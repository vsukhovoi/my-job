## 🏭 КРОК 19.1. Фабрика `PaymentTransactionFactory`

Таблиця `payment_processed_events` не має auto-increment — PK складений (`event_id` + `gateway`). Фабрика потрібна для зручного створення тестових записів.

`database/factories/PaymentTransactionFactory.php`:

```php
<?php

declare(strict_types=1);

namespace Database\Factories;

use App\Models\PaymentTransaction;
use App\Models\Vacancy;
use App\Payments\CheckoutService;
use Illuminate\Database\Eloquent\Factories\Factory;

class PaymentTransactionFactory extends Factory
{
    protected $model = PaymentTransaction::class;

    public function definition(): array
    {
        $gateway  = $this->faker->randomElement(['mono', 'wayforpay', 'liqpay', 'stripe']);
        $days     = $this->faker->randomElement([15, 30, 90]);
        $vacancyId = 1; // default — override у тестах

        return [
            'event_id'     => $gateway . '_' . $this->faker->unique()->uuid(),
            'gateway'      => $gateway,
            'order_id'     => CheckoutService::buildOrderId($vacancyId, $days),
            'processed_at' => now(),
        ];
    }

    // States

    public function mono(): static
    {
        return $this->state(['gateway' => 'mono']);
    }

    public function liqpay(): static
    {
        return $this->state(['gateway' => 'liqpay']);
    }

    public function wayforpay(): static
    {
        return $this->state(['gateway' => 'wayforpay']);
    }

    public function stripe(): static
    {
        return $this->state(['gateway' => 'stripe']);
    }

    public function forVacancy(Vacancy $vacancy, int $days = 30): static
    {
        return $this->state([
            'order_id' => CheckoutService::buildOrderId($vacancy->id, $days),
        ]);
    }

    public function daysAgo(int $days): static
    {
        return $this->state(['processed_at' => now()->subDays($days)]);
    }

    public function today(): static
    {
        return $this->state(['processed_at' => now()]);
    }

    public function thisMonth(): static
    {
        return $this->state(['processed_at' => now()->startOfMonth()->addDays(5)]);
    }

    public function lastMonth(): static
    {
        return $this->state([
            'processed_at' => now()->subMonth()->startOfMonth()->addDays(5),
        ]);
    }
}
```

## ⚠️ Критичні нюанси тестів

### 1. `PaymentTransactionFactory` — PK без auto-increment

`event_id` — рядок, не integer. Фабрика генерує через `$gateway . '_' . $faker->unique()->uuid()`. Якщо два тести створюють одну й ту саму подію — буде collision. `->unique()` вирішує.

### 2. Ізоляція в `BillingControllerTest` — головний тест

Тест «роботодавець бачить тільки свої транзакції» — найважливіший у всьому модулі 19. Якщо він падає — `BillingController` має вразливість витоку даних між роботодавцями. Не пропускай.

### 3. `isConfirmed` — перевірка `expires_at > startedAt`, а не `status === Active`

Тест «`isConfirmed = false` якщо expires_at не змінився» перевіряє що вакансія, яка **вже була** Active до оплати, не дає false positive. Це граничний кейс: без цього тесту баг міг би залишитись непоміченим.

### 4. `PaymentStatsWidget` — тест тренду через колір

Прямо перевірити числовий тренд через Livewire API складно. Замість цього перевіряємо колір (`success` якщо тренд позитивний) — непряма але надійна перевірка.

### 5. `VacancyStatsWidget` — один запит, не чотири

Якщо хтось реструктурує `getStats()` на чотири окремих `COUNT` — тест на числа все одно пройде. Але можна додати окремий assertion через `DB::getQueryLog()`:

```php
DB::enableQueryLog();
Livewire::test(VacancyStatsWidget::class)->instance()->getStats();
$log = DB::getQueryLog();
expect(count($log))->toBeLessThanOrEqual(2); // максимум 2 запити (stats + chart)
```

### 6. Mocking `CheckoutService` в `VacancyExtendController`

Тест `initiate` мокає `CheckoutService` — без цього тест намагається реально підключитися до MonoPay/Stripe. Переконайся що `$this->mock(CheckoutService::class, ...)` спрацьовує (Mockery автоматично розв'язується з Laravel DI контейнера).
