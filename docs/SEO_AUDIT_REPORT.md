## Топ-5 пріоритетних дій перед повним запуском

1. **🔴 Фасетна навігація (A4.1 + A6.3)** — додати `noindex` або canonical для сторінок з активними фільтрами. Найвищий ризик: сотні дублюючих URL роздують краул-бюджет і знизять ранжування основних сторінок.

2. **🔴 Легальна термінологія (D1.1–D1.3)** — замінити "Пошук роботи" на "Оголошення/перегляд вакансій" у `SeoService` та layout fallback. Прямий юридичний ризик + порушення брендбуку.

3. **🔴 `url` поле у JobPosting schema (C1.7)** — Google вимагає поле `url` у JobPosting. Без нього Google for Jobs може не показувати вакансії у відповідному блоці SERP.

4. **🔴 Under-construction зображення у production layout (B7.2)** — `<img src="under-construction.webp">` рендериться в `layouts/app.blade.php` на КОЖНІЙ сторінці для авторизованих та гостьових користувачів. Шкодить UX і сигналам E-E-A-T.

5. **❌ BreadcrumbList JSON-LD (C3.1) + Canonical для статичних сторінок (A3.3)** — breadcrumb без розмітки не дає rich snippet у Google; статичні сторінки без canonical можуть накопичувати дублікати.
